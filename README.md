# Kira PC Control Updates

Public binary update channel for the **Kira PC Control Transfer** distribution.

- The current canonical Transfer app version is **2.1.26.4**, a downstream patch on the **2.1.26** base.
- Transfer checks this repository only and does not download CoS binaries.
- Application source code is not published here; release assets contain the Transfer installer and matching extension.
- `v2.1.029` is the three-part **compatibility carrier** containing byte-for-byte identical 2.1.26.4 assets so already-installed Transfer 2.1.26 clients can discover the patch with their legacy updater. The installed app still reports **2.1.26.4**.

Canonical release: **v2.1.26.4**.
Legacy updater carrier: **v2.1.029** (marked Latest so legacy 2.1.26 clients discover it).
